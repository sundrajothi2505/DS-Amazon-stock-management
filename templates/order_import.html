How this works

  • Looks for columns like order date, order ID, description, quantity, shipping date, and delivery/return status — spelled however your sheet has them.
  • Each order is matched by its order number, so it's safe to re-run this later or re-upload an updated file — anything already imported is left alone, nothing is duplicated.
  • Product descriptions are imported as text rather than auto-matched to a specific catalog SKU, since similar variants (colors, sizes) can't be told apart reliably from a short description. You can link a specific product afterward from the order's Edit page if you want to.
  • This only adds order records — it does not change any stock numbers.
