How this works

  • New SKUs in the file are added as new products, with starting stock set from the report's quantity column.
  • Existing SKUs get their name and ASIN refreshed if Amazon's listing changed.
  • If the report's quantity is different from what's tracked here, a logged adjustment is created for the difference — never a silent overwrite, so it still shows up in History with your name on it.
  • Safe to re-run any time you export a fresh report — already-matching products are simply left alone.
